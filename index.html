How it is made

From a check-in to a dataset you can ask about

Check-inEach builder checks in on-chain with the IslandDAO app. The venue key co-signs.
IndexOur own indexer decodes the check-in program, built from Envio's open IslandDAO demo.
ProveCounts match the chain: 251 of 251 attendance accounts, and the reference indexer exactly.
DatasetGecko keeps a daily dataset, refreshed for free, with the source and time on every value.
JoinMilestones from public posts are matched to the event. For now this join is done by hand; a join step inside Gecko is in review.
AskThe same dataset answers questions in Claude or any MCP client.
  • Aggregates only. No wallet addresses, no names, no group under 5.
  • Numbers count check-in identifiers, one per account, not verified people.
  • Days follow the program's own rule: local days in Florianópolis (UTC−3).

Built by Gecko for IslandHack V5. Attendance comes from IslandDAO's on-chain check-in system. The indexer started from Envio's open IslandDAO demo.
